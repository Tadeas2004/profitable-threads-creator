# Profitable Threads Creator — Landing Page

> Sales landing page for a social media info product. Built, marketed, and shipped end-to-end as a solo project.

---

## What this is

A conversion-focused landing page for **Profitable Threads Creator** — an info product teaching people how to grow an audience on Threads and monetize it.

The page was designed, coded, and marketed entirely by me — from copywriting and visual design to payment integration and deployment.

**Live site:** [profitablethreads.com](https://profitablethreads.com)

---

## Tech stack

| Layer         | Technology                                           |
| ------------- | ---------------------------------------------------- |
| Markup        | HTML5 (semantic)                                     |
| Styling       | CSS3 — custom properties, flexbox, responsive layout |
| Interactivity | Vanilla JavaScript                                   |
| Payments      | Gumroad checkout integration                         |
| Hosting       | Cloudflare Pages — custom domain, global CDN         |

No frameworks, no build tools — intentional choice to keep the page fast and the codebase simple.

---

## Key features

- **Responsive layout** — mobile-first design, tested across screen sizes
- **Gumroad checkout** — embedded buy button with direct payment flow
- **Optimized for conversion** — single CTA, social proof section, benefit-focused copy

---

## What I built and why

This project started as a real business problem: I wanted to sell a course I created. Instead of using a no-code page builder, I built the landing page from scratch — which gave me full control over performance, design, and the checkout flow.

The product teaches audience building and monetization on Threads. The landing page had to reflect that — clean, direct, and credible.
